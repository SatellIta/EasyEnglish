# EasyEnglish

[English](README.md) | **简体中文**

EasyEnglish 是一个本地优先的英语学习工具，面向中文母语者。它把单词、短语和完整句子放在同一个词库里，用「先辨别、再学习」的两阶段流程帮助你认识新内容，再用间隔重复安排复习。

项目刻意保持轻量：一个 Vue 单页应用、一个 Hono 进程、一个 SQLite 文件。词库、复习记录和对话历史都保存在你自己的电脑上。

## 功能

- **不只记单词，也记短语和句子。** 每条内容都可以保存中文释义、补充说明、例句、音标、笔记、标签和图片。可以按类型、标签、日期或场景搜索和筛选。英文内容重复时会在入库前提示。

- **保留丰富字段的 Anki 导入。** 支持导入 `.apkg` 牌组和 `.colpkg` 集合包，保留中文释义、英英释义、音标、例句、标签和引用图片。预览界面可以重新映射字段、选择笔记类型，并决定重复项是跳过、更新还是新建。弹窗里提供 AnkiWeb 外链，方便你在浏览器自行查找并下载共享牌组，再回到这里上传。

- **两阶段学习流程。** 每次选择一组词，也可以只从某个 Anki 标签组里抽词。先整组判断「认识 / 不认识」，再只学习不认识的词，并查看词库里的完整信息。认识的词一天后复习，不认识的词立即进入复习队列。

- **主动回忆式间隔重复。** 新词条立即到期，之后按可配置的艾宾浩斯阶梯推进（默认 1/2/4/7/15/30/60/120/240 天）。遗忘后会在设定的重试窗口后重新出现。复习时只先显示英文，主动回忆后再展开答案。

- **会参考你词库的 AI 助手。** 可以询问词义、辨析、语法和地道表达，AI 会读取你保存过的词句作为联想记忆。支持选择或自定义人格，也能围绕某个场景进行角色扮演对话。回答以流式方式逐字显示。

- **每日总结。** 让 AI 把当天的对话和新学词条整理成可复习的总结，同时抽取值得加入词库的候选条目，并记录反复出现的错误。整理任务在后台运行，切换页面不会中断。

- **四种词库浏览方式。** 可以按日期、类型、标签或场景查看，支持关键词搜索以及按时间或字典顺序排序。点击词条标题可以直接打开完整详情，也可以一键进入编辑。批量删除支持按类型、标签、日期或场景选择，分类内可全选，删除前会显示精确数量并二次确认。

- **用场景做联想记忆。** 可以把相关的词和句子归入旅行、工作、某部电影等自定义场景。场景词条默认进入每日复习，场景详情页提供「全部加入复习 / 全部移出复习」的一键切换。加入场景不会改变已有词条自己的复习开关。

- **Markdown 导入、导出与文件同步。** 使用 `# words`、`# collocations`、`# sentences` 或 `# Scenery` 组织内容，表格支持含义、英英释义、例句、音标和标签等具名列。HTML 注释不会参与导入，方便保留自己的备注。还可以在设置里保存一个本地 Markdown 文件路径，之后从复习页一键同步，让新表达立刻进入复习。

- **发音与跟读练习。** 使用浏览器内置语音合成朗读英文，不需要额外音频文件。支持的浏览器里还可以开启跟读模式，用语音识别比较你的发音和目标句子，并在本地给出反馈。

- **两套主题，均有深浅色模式。** 在设置里可以选择新拟物派或瑞士国际风格，在侧栏切换深色 / 浅色。界面支持中文和英文。

- **数据默认留在本地。** 所有内容保存在 `data/easy-english.db`，包含全文检索，没有云端账号，也没有遥测。备份只需复制 `data/` 目录；请不要把它或 `.env` 提交到公开仓库。

## 快速开始

要求：**Node.js 24+** 和 **pnpm 11+**。

```bash
pnpm install
pnpm dev
```

打开 <http://localhost:5173>。Hono API 运行在 3001 端口，Vite 会把 `/api` 代理过去。

AI 是可选的。没有配置模型时，词库、学习、复习、Markdown 导入导出和 Anki 导入都可以正常使用；对话和总结会返回友好的「尚未配置」提示。需要 AI 时，进入 **设置 → AI**，选择预设或填写任意 OpenAI 兼容接口的 Base URL、模型和 API Key，然后测试连接。

| 服务 | Base URL | 模型示例 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Ollama（本地） | `http://localhost:11434/v1` | `qwen2.5:7b` |

也可以复制 `.env.example` 为 `.env`，填写 `EASYENGLISH_BASE_URL`、`EASYENGLISH_API_KEY` 和 `EASYENGLISH_MODEL`。设置页保存的配置优先级更高。

## 一个典型的使用流程

1. 手动添加词条，或用 Markdown / Anki 导入已有内容。
2. 打开「学习」，选择每组数量，可选一个标签组，然后逐条判断认识与否。
3. 学习不认识的词，完成后它们会进入复习队列。
4. 每天花几分钟复习，间隔由调度器自动安排。
5. 遇到问题时随时和 AI 对话，晚上生成当天的学习总结。

## 常用命令

```bash
pnpm dev          # 同时启动 Hono (3001) 和 Vite (5173)
pnpm dev:server   # 只启动后端
pnpm dev:web      # 只启动前端
pnpm build        # 类型检查并构建到 dist/
pnpm start        # 生产模式，由 Hono 同时提供 API 和静态页面 (3001)
pnpm typecheck    # 仅类型检查
```

## 技术栈

- 前端：Vue 3、TypeScript、Vite、Vue Router、Pinia、marked + DOMPurify
- 后端：Hono、better-sqlite3（SQLite + FTS5），读取 Anki 数据库时使用 Node 内置的 `node:sqlite`
- AI：任意 OpenAI 兼容的 Chat Completions 接口，使用 NDJSON 流式返回
- UI：纯 CSS 变量，无组件库

项目刻意保持轻量：没有 ORM、没有 UI 组件库，也没有外部数据库服务。

## 数据与备份

数据库默认位于 `data/easy-english.db`（可用 `DB_PATH` 覆盖）。`data/`、`test/`、`.env` 和导入的 Anki 包都已经加入 `.gitignore`。API Key 和复习记录只保存在本地 SQLite 中，接口只返回掩码。这个项目定位为个人本地应用，请像对待私人学习笔记一样对待数据库。

## 我为什么开发 EasyEnglish

大多数背单词软件是围绕「单词」设计的，但我真正想记住的，往往是阅读、听播客或和人聊天时遇到的短语、搭配和完整句子——这些内容很难被一个单词列表装下。

我也想要一个把 AI 当作工作流一部分、而不是外挂的英语学习工具：一个能看见我已经记录了什么、能结合语境讨论细微差别，并帮我把日常遇到的内容变成真正会去复习的材料的助手。

EasyEnglish 是我为自己搭的这样一个空间：一个安静的、本地优先的短语和句子笔记本，配上恰到好处的 AI 和间隔重复，让这些表达真正留下来。如果它对你也有用，我会非常开心。
