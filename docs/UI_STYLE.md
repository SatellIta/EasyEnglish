## 当前基线

在正式风格提示词到位前，界面采用一套中性的暖色纸张风格，全部由 `src/styles/main.css` 顶部的 CSS 变量驱动：

- 背景：暖纸色 `--bg`，表面 `--surface`，边框 `--border`
- 主色：深绿 `--primary`，强调色：琥珀 `--accent`
- 标题：衬线字体 `--font-serif`；正文：系统无衬线 `--font-sans`
- 圆角：`--radius` / `--radius-lg`；阴影：`--shadow`

## 实现约定

1. 颜色、字体、间距、圆角、阴影优先使用 `:root` 变量，不要在页面里散落硬编码色值。
2. 页面级特殊布局可以用 `<style scoped>`，但通用组件（按钮、卡片、表单、标签、Markdown、弹窗）保持全局类。
3. 不引入 UI 组件库；如风格提示词要求图标或字体，先确认是否允许新增依赖或外部资源。
4. 响应式断点保持在 900px（布局从侧栏变顶栏）与 560px（紧凑移动端）附近。
5. 修改风格后，用桌面（1440px）和手机（390px）两种视口检查：今日、对话、复习、词库、设置五个页面。
6. AI 生成的 Markdown 必须继续经过 DOMPurify 清洗，不能为了让样式生效而放宽清洗规则。
